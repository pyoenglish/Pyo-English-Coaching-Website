PYO! ENGLISH COACHING — WEBSITE REBUILD
=======================================

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or another browser.
3. You can test the site before making any changes to the live website.

HOW TO PUBLISH
- If your site is deployed from GitHub to Cloudflare Pages, upload the files in
  this directory to the site's repository root, preserving the assets folder.
- Commit the changes and Cloudflare Pages should deploy according to your
  existing build settings. For a plain HTML site, set the build output
  directory to / or the directory containing index.html as appropriate.
- Create a backup of your existing site FIRST. Publishing replaces the old
  homepage if you overwrite index.html.
